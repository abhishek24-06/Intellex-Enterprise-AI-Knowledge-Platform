## 3. Task Tracking

Each task has an owner, priority, status, and next action. Private notes can contain details that are unnecessary for a broader department audience.


## 4. Analysis Workflow

The workflow starts with collecting the relevant input, validating the assumptions, performing the analysis, checking the result, and recording a concise conclusion.


## 5. Validation

Validation should identify calculation errors, missing supporting information, and inconsistencies. A failed validation should create a follow-up item.


## 6. Follow-up

Follow-up actions should identify the next step and a useful completion condition. The purpose is to keep private project work actionable rather than simply storing observations.
