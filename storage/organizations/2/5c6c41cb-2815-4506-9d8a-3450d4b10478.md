# Network Security Guidelines

## Purpose

This document defines the minimum security standards that every employee must follow while accessing company resources.

## Password Policy

- Passwords must contain at least 12 characters.
- Passwords must include uppercase, lowercase, numbers, and special characters.
- Passwords expire every 90 days.

## Multi-Factor Authentication

- MFA is mandatory for all employees.
- Hardware security keys are recommended for administrators.

## Device Security

- Company laptops must use full disk encryption.
- Operating systems must be updated regularly.
- Antivirus software must remain enabled at all times.

## Network Access

- Only company-approved VPNs may be used when working remotely.
- Public Wi-Fi should be avoided unless connected through the corporate VPN.

## Incident Reporting

If a security incident is suspected, immediately notify the IT Security Team and create an incident report within one hour.
