# Finance Department Budget Policy

**Visibility:** DEPARTMENT: Finance

**ACL Test Marker:** `DEPT-FINANCE-03-GAMMA`


## 1. Policy Scope

This policy defines the internal budgeting workflow used by the Finance department. It covers request intake, validation, allocation, forecasting, variance review, documentation, and approval. The content is intentionally department-restricted so it can be distinguished from organization-wide guidance.


## 2. Budget Requests

A budget request should identify the requesting function, business purpose, expected cost, requested period, supporting rationale, and approval path. Finance reviewers validate that the request contains enough information to make a consistent decision.

## 3. Validation

Validation checks should confirm arithmetic, supporting records, category classification, and timing. When a request is incomplete, the reviewer records the missing information instead of silently making assumptions.


## 4. Allocation

Approved allocations should be recorded against the appropriate budget category. The allocation record should make it possible to compare planned spending with later actual spending.


## 5. Forecasting

Forecasts are updated when material assumptions change. A revised forecast should state the reason for the revision and the period affected. Historical versions should remain distinguishable from the current forecast.


## 6. Variance Analysis

Variance analysis compares actual spending with approved or forecast values. Large or unexpected variances should be investigated and documented with a short explanation.


## 7. Quarterly Review

Quarterly review provides an opportunity to identify recurring variances, unplanned expenditure, and changes in expected demand. The review should result in actionable follow-up rather than simply recording a number.
